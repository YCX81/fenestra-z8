Both opt-ins are false by default; even master TX drain enabled alone accepts no transfer in this merged port. New read and schedule call sites return immediately when inactive. Existing branches and status write semantics are retained. There is no host audio API in the merged port and no route into the existing32-bit host sink. Ring and SFX are separate admitted tuples: ring192000-byte request27/28 banks versus single request27/4800-byte sound. Overlap, mixed bank lengths, duplicate owners, unsupported format controls and the zero-length→262144-byte underflow are rejected.

A successful callback reads the admitted RAM range, captures/hashes the bytes, updates counters and only then calls original `pdma_progress`. Independently tested read failure and budget exhaustion give no IRQ. Original TX disable cancels the timer and resets phase. Legitimate rearm starts a fresh deadline. Rearming the future bank does not shift the currently selected bank's deadline. A late callback after stop cannot complete a transfer.

The serial mode word is observed and the sample-duration getter accepts the explicit4800-byte sound input as25ms. Other divider/PLL semantics, physical FIFO depth, DAC conversion, speaker routing and acoustic timing are not established by these tests. Therefore four192000-byte reads do not prove that an actual speaker played for four seconds.
