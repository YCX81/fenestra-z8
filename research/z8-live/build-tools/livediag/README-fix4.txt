Nikon Z8 测试包 3e（Live 修复 v3 + USB 可调参数 + 事件日志）
基础：测试包 3a（MAIN 919a6545）+ Live 修复 v1/v2/v3 + 可调参数与事件日志。版本标识 04.05.p0，以 SHA-256 辨认。

这一版的目的：以后多数调整不用再刷机
- 可调参数（通过 USB 写入，下一帧生效，关机后恢复默认）：
  late_max（复制期间允许新来的帧数，-1=自动=缓冲区数-2，0=严格）、soft_cancel（拍照取消时保留片段，默认 1）、
  window_us（快门前后窗口，默认 1.5 秒）、sample_us（编码最小间隔）、stale_us（过期帧阈值）、short_start（找不到 1.5 秒前关键帧时用更短片段）、
  geometry_reset_us（尺寸长期变化多久后重置）、audio（录音开关）、ready_fresh_us（就绪要求最近一帧的新鲜度）。
- 事件日志（最近 128 条，带时间戳）：快门、接受/忽略、每次取消的来源（取景引擎/拍照内存池）、尺寸变化、申请失败、
  冻结片段、写 MOV 开始/结束及错误码、原厂写文件、就绪、编码错误。
- 编码分段计时：写入、等硬件、读出、解析。

Live 修复内容（v1–v3，详见各自说明）
- 取景画面整块读取（417 ms → 27 ms/帧）；6 块缓冲区轮换下复制期间来 ≤4 帧仍接受。
- 编码输入/输出整块读写（435 ms → 194 ms/帧，仍在查）。
- 尺寸变化只跳帧不清空；申请失败等待重试；找不到 1.5 秒前关键帧时用更短片段。
- v3：拍照时取景引擎停止/拍照内存池导致的取消，只丢正在复制的一帧，保留已编码的片段、录制任务和快门。

验证
- 电脑上重放真机时序（30 帧/秒、6 块缓冲、复制 27 ms、编码 194 ms、快门后取景暂停与尺寸变化、内存池锁定）：
  关闭软取消（等同 v2）时快门丢失，与相机上看到的一致；打开软取消（v3/本版）时 5 种场景都录成片段。
- 转换/整块复制函数：Unicorn 中与参考逐字节一致。
- QEMU（MAIN 54cc3272）：关闭 Live 单拍 2/2 正常；打开 Live 连拍 3 次：1 次停在 Wave5（与 3a 相同），
  2 次遇到 QEMU 已知的"退出菜单后取景不重启"（3a 原版也有），没有新故障。

测试
1. 刷机后打开 Live，等图标变绿，拍 1 张，等 5 秒再拍 1 张；回放看 LIVE 标识和 REC 播放。
2. 接 USB（必要时手动打开 USB Debug），由我运行 livectl.py 读状态和日志；需要时在线改参数后你再拍，不用刷机。
