# Live 状态图标方案

所有图像由 `draw_icons.py` 使用 Python 标准库程序化绘制，未调用 GPT Image。内置 GPT Image 的默认保存位置在当前目录之外，无法指定输出路径，因此本次优先遵守“只在 icons/ 内写文件”的限制。没有访问相机，没有修改固件或其他目录。

## 方案

1. **画框脉冲**：静态画框内嵌方波，表示照片含有时间变化。造型简洁，但可能被理解为信号或音频。
2. **照片拖影（推荐）**：带山形和亮点的照片前方露出两段历史画框，表示照片及其连续瞬间；照片语义最直接。
3. **前后时刻**：中央主画格与两侧短画格组合，强调一张主照片及前后时间片段，造型更抽象。

普通状态右侧为两枚开放折角，提示运动。忙碌状态保留各方案主体，右侧改为向下箭头与托盘，表示正在写入；这是静态忙碌标记，不表示进度百分比。三套方案均为本次自行组合的几何造型，未引用厂商图标、商标或同心圆图案。

## 文件规格

- `option-N-large.png`：1792×704，按同一几何定义以 16 倍坐标绘制，纯黑白。
- `option-N-112x44.png`：112×44，普通状态。
- `option-N-busy-112x44.png`：112×44，忙碌状态。
- `preview.png`：1024×704；左列普通、右列忙碌，行号 1–3；图标严格最近邻放大 4 倍。
- 所有 PNG 为 8 位 RGBA，背景不透明黑色，图形不透明白色，alpha 全部为 255。
- 小图直接在整数像素网格绘制，主要线宽 3 px，无缩小重采样、抗锯齿、灰阶、阴影或渐变。
- 图标画布本身不含界面坐标偏移；由调用方在 (24,24) 放置整个 112×44 图块。
- 已检查预览，并在脚本中验证小图尺寸、数据长度及仅有黑白两种 RGBA 值。未做相机实机验证。

复现：在此目录运行 `python3 draw_icons.py`。脚本只写入自身所在目录，会重新生成这十张 PNG。
