# Independent review: external PCM STOP race and clock coordinates

Reviewed exact driver `c388a9256e4150b6c4e48166f240f93615d44bec0c3069fae717ec7aee5abda1` and feeder `cbbbd8fa21f1d0b422c9facf18d54f7464551c3df62ca1298a6835dfdd474cb2` from `audio/core-pcm-counter-f`. No production source or model is changed by these two deltas. They are suitable for the next same-F functional run; this is not a claim that that run has already passed.

The exact private model's `set_serial5_pcm16_input` emits the admitted exception before parsing payload bytes, writing guest RAM, incrementing block/IRQ counters or advancing DMA. The driver handles only that exact structured GenericError, with a previously ready bank, a fresh ready=false/RX-request-bit-off snapshot, and unchanged block and IRQ counts. All other errors remain fatal, including RAM-write failure, unexpected tuple changes with RX still enabled and any counter movement. Accepted cancellation records both snapshots, payload hash and error in a separate log. It supplies no replacement block, IRQ or guest state; the following real RX epoch receives a fresh deadline.

Read-only inspection confirms that the private board sets the ARM counter frequency to 24 MHz, QEMU uses an integer 41 ns counter period, and the actual Live runtime divides counter ticks by CNTFRQ. Thus floor(floor(QOM_ns/41)/24) equals floor(QOM_ns/984). A 2400-frame/48 kHz external block represents 50,000 guest microseconds, or 49,200,000 QOM ns. The new input schedule uses that coordinate conversion. CPU clock/CNTFRQ, firmware freshness/Ready thresholds, native service timeouts and model tuple gates are unchanged.

Actual source functions independently passed 500 rearm cycles without deadline drift, all 16 Ready conjunctions and bounded 60-second failure, 36 stop-gate combinations (only the exact stopped/no-consumption case accepted), four other-error cases, real-stop epoch reset and the integer coordinate identity. Evidence is `counter-feeder-review.json` and `test_counter_feeder_review.py`. Before capture commits, missed input at the unchanged two-block lateness threshold remains fatal. Only already committed postcapture test stimulus may explicitly log/drop expired blocks, never backfill stale audio.

This aligns an explicit functional input to the emulator's existing guest time coordinate. It does not validate the physical ADC oscillator or promise gap-free sound. Native stop cancels an external block that is no longer admissible; that cancellation must remain visible, and it must not be relabeled as delivered PCM.
