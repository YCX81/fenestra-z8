## 验证

- `layout-final-machine.json`：1676 次真实 ARM 执行 PASS，覆盖 419 条记录的原始/修后 × 横屏/竖屏。LCD 执行原始 ID 匹配/缓存代码，EVF 执行原始查表/尺寸选择/缓存代码；另 16 个 gate/auto-rotate/左竖/右竖/正反方向组合 PASS。
- `timer-machine.json`：12 次真实计时更新和矩形选择 PASS；字体、渲染及格式化外部 API 为桩。
- `overlay-check.json`：1255 项非空原生照片矩形对应记录均 byte-identical；全部横屏矩形不变；旧记录不符时拒绝；其他独立集成变化保留；反向还原得到原输入。
- 主集成正在独立 QEMU lane 验证 Live/REC。此子任务的布局证据是原厂 ARM 代码执行与边界计算，**没有宣称完整竖屏视频画面已在 QEMU 或真机目视通过**。旧 portrait 整机 lane 缺显示/传感器模型，未继续盲加模型。
- 原厂另有 4 张简洁/特殊场景表，本补丁未全量重排；没有将其是否触发归因于用户遇到的问题。主显示的实际记录已明确修改，不以仅补未知场景表充当修复。

## 集成

直接对尚未叠此 v52 portrait 补丁的 MAIN 运行：

```
python3 apply_portrait52_final.py INPUT OUTPUT --reference ../timing/v51d.main
```

依赖同目录 `apply_portrait52.py`、`evf_layout.py`、`lcd_layout.py`、`layout_data.py`。不要先跑旧的仅 EVF 脚本再跑本脚本；完整记录校验会正确拒绝二次叠加。reference SHA 固定，但 INPUT 允许独立 Live/PB 更新；root 负责后续 Bootguard、build ID、总 manifest 与打包。未使用 USB、相机或物理卡。
