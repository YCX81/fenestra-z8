一、问题
- 相机语言为中文（简/繁）、日文或韩文时，原厂 CJK 字体把英文字母画成等宽半角，而且部分 ASCII 码位是图标：小写 q 显示成一个圆形图标，所以 “Live Photo: Requested” 中间缺字。
- Fenestra 新增的所有文字（Fenestra、Auto activate、USB Debug、Live Photo…）都用原厂第 0 号字体类别，在这几种语言下就落到这套 CJK 字体上。

二、修改
- Live 层在安装菜单时复制一份原厂的“字体类别 -> 各语言字体”表（0xA02F2AC28），在末尾加一个第 18 号类别：
  中文简体、中文繁体、日文、韩文用英文界面的拉丁字体（字号与英文界面相同），其余语言与第 0 号类别完全相同。
- 只把 Fenestra 文字库里新增的文字 ID（3154 以上）改到第 18 号类别。原厂文字 ID 和原厂表本身都不改。
- 英文等拉丁语言界面显示与 v39 完全相同。

三、建议的真机检查
1. 相机语言切到简体中文：设定菜单 -> Fenestra，各行英文应为尼康英文界面的比例字体；Live Photo 选 On 后显示 “Live Photo: Requested”，q 完整。
2. 进入 Live Photo 页：On / Off / Shutter sound 显示正常。
3. 切回英文，确认显示与以前一样。
4. 原厂中文菜单（含英文缩写的条目，如 HDMI、USB）应与原厂一致，没有变化。

四、验证范围
- QEMU（本机区域只能选 English / 日本語）：日文下 Fenestra 页、Live 页文字为比例拉丁字体，“Requested” 完整；英文对照与 v39 一致；原厂日文菜单不变。
- 中文/韩文的字体映射与日文同一逻辑（只是查表下标不同），QEMU 中无法选这两种语言，未直接截图验证。
