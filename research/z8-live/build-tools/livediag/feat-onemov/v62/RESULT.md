## 修复依据与行为

用户提供的 IMG_5033 / IMG_5034 显示视频 Log 行、子菜单标题和三个选项空白。原文字在 36 种语言表中均存在，但编号与 Fenestra 动态 UI 重叠；Modules 管理对象在退出后常驻，错误地把这些编号解析成空格。V62 用真实原厂当前菜单页判定文字归属，恢复 Log / Log设定 / N-Log / S-Log3 / Log3G10，并保留扩展页本身的有效空字符串行为。使用独立 80 B wrapper，没有改动原 UI miss 分支。证据见 menu/final-text-results.md 和 menu/final-context-arm-results.json。

Live 快门交接从 V56 起被 allowed() 恒零完全禁用；旧启用代码又仅接受音型 1/2，不能处理用户日志中的音型 10。V62 恢复原厂有限音型的麦克风→扬声器→麦克风交接，增加 prepare 共同静音入口，使 Live Off 同时抑制 prepare/fire；并将录音所有权与发声许可分开，修复交接途中切 Off 后麦克风无法恢复的问题。On 保留原厂 Silent 和资格判断；没有强制音量、伪造完成或扩大循环/Bulb 协议。证据见 shutter/RESULT.md。

用户已明确确认 V61 在 RAW 优先、双卡 RAW/JPEG 分存时标志、播放与返回正常。V62 回放完整 bank 与 PB ELF 均逐字节不变，视频 freeze() 的 552 B 机器码也不变。

## 实机边界

V62 尚未经相机屏幕或扬声器验收。模型证明原厂音频输出与录音恢复，不能证明实际响度、切换噪声和硬件调度。开启快门音需暂停共用硬件上的麦克风，Live 音轨会插入静音；此次 tone10 模型为 0.25675 秒，Off 未出现 ≥10 ms 静音段。视频音频不是无缝录制承诺。

On-r2 尾帧未输出的原因及实机表现未确认，没有将此尾部问题扩大纳入本次菜单/快门声代码修改；V61/V62 的回放与视频 freeze 代码保持相同，并不证明该观察在 V61 上也一定发生。新片回放是重启后单卡模型验收，不能表述为同 boot 或实体双卡验收。V61 的双卡实机反馈是用户提供的独立事实；本版通过回放字节一致性保留其代码。
